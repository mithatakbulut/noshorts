Install on iPhone

01
Install Userscripts

Install the Userscripts Safari extension from the App Store and enable it in Safari.

02
Add noshorts.user.js

Add the userscript to Userscripts and allow it to run on youtube.com.

03
Open YouTube in Safari

Normal YouTube stays intact. Shorts links, shelves, and routes are removed.

What it removes

Shorts feedHides Shorts shelves and cards from YouTube pages.
/shorts routesStops navigation into the infinite Shorts viewer.
Dynamic Shorts UIHandles content inserted later by YouTube's SPA.
Nothing elseRegular videos, search, channels and subscriptions keep working.

Why?

YouTube does not provide a permanent setting to disable Shorts. No Shorts is intentionally tiny: it solves that one problem without replacing YouTube or adding another subscription.
